# Barbie × Minecraft Kindergeburtstag – GitHub Pages

## Zwei verschiedene Wunschlisten
Die Seite kann über einen URL-Parameter automatisch nur die passende Wunschliste anzeigen:

- Jonas: `https://DEINE-SEITE.github.io/DEIN-REPO/?kind=jonas`
- Lilith: `https://DEINE-SEITE.github.io/DEIN-REPO/?kind=lilith`

Damit kannst du auf Jonas' Einladungen nur den Jonas-Link drucken und auf Liliths Einladungen nur den Lilith-Link.

Wenn jemand die Seite ohne Parameter öffnet, erscheinen zwei Auswahlbuttons:
**Von Jonas** / **Von Lilith**.

## Amazon-Links eintragen
In `index.html` gibt es zwei Stellen mit:

```html
href="https://www.amazon.de/"
```

Die erste gehört zu Jonas, die zweite zu Lilith. Dort jeweils die passende Amazon-Wunschliste eintragen.

## Party-Daten anpassen
In `index.html` nach `EINFÜGEN` suchen und Datum/Uhrzeit/Antwortfrist ersetzen.

## GitHub Pages aktivieren
1. Dateien in ein GitHub-Repository hochladen.
2. Repository → **Settings** → **Pages**.
3. **Deploy from a branch** auswählen.
4. Branch `main` und Ordner `/ (root)` auswählen.
5. Speichern.

## Datenschutz
Die GitHub-Pages-Seite ist öffentlich. Daher besser keine vollständige Wohnadresse,
Telefonnummer oder andere private Daten direkt auf die Webseite schreiben.
